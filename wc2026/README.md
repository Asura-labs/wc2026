# ⚽ WC 2026 Prediction League

App για προβλέψεις του Μουντιάλ 2026 με κοινό leaderboard για την παρέα.

## 🔑 Πριν το deploy

Άνοιξε το `src/App.jsx` και βάλε τα Supabase κλειδιά σου στην κορυφή:

```javascript
const SUPABASE_URL = "https://το-δικο-σου.supabase.co";
const SUPABASE_KEY = "το-anon-public-key-σου";
```

## 🚀 Deploy

Δες το αρχείο **ΟΔΗΓΟΣ-LIVE.md** για αναλυτικές οδηγίες βήμα-βήμα.

Γρήγορη εκδοχή:
1. Φτιάξε project στο [Supabase](https://supabase.com) + τρέξε το SQL (στον οδηγό)
2. Ανέβασε αυτόν τον φάκελο στο [GitHub](https://github.com)
3. Σύνδεσέ το με το [Vercel](https://vercel.com) → Deploy
4. Μοιράσου το link!

## 💻 Τοπικά (προαιρετικό)

```bash
npm install
npm run dev
```

## 👤 Admin

Default: `admin` / `admin123` — **άλλαξέ το** από το Supabase Table Editor!
